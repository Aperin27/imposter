# Stage 2 contract

- Preserve the single Worker, SQLite Durable Object per room, hibernating WebSockets, gameplay, styles and sessionStorage lifetime. No publishing or account changes.
- Local SVG QR codes encode only `new URL('/?join=CODE', currentOrigin)`. Invite links prefill the form, never join automatically or replace an existing session. Existing participants receive an explanatory notice and can leave explicitly before using another invite.
- Add optional persisted fields for disconnect times, revoked credentials, stable question IDs and timestamped notices. Upgrade on load, without resetting room records or alarms. Legacy offline members get a fresh 90-second grace; active round snapshots stay unchanged.
- Host-only offline removal checks membership, current host, offline duration and the exact disconnect timestamp confirmed by the host. Remove and reconnect serialize in the same Durable Object lock: reconnect first rejects removal; removal first permanently revokes that credential for this room's lifetime. Round participants, question text, imposter, answers and deadlines remain untouched.
- Freeze the Stage 1 index-to-ID mapping independently of bank order. Convert history once; select from currently available unused IDs. Removed IDs do not prevent a cycle reset; additions remain eligible. Do not reuse IDs for different pairs.
- Use built-in Workers rate limit bindings, separate create/join allowances (10/60 seconds and 60/60 seconds per trusted Cloudflare client IP). Existing membership joins, resume, socket upgrade and heartbeat bypass these limits. Allow shared Wi-Fi groups, return 429 plus Retry-After, and document approximate per-location counters and shared-IP limitations. No paid integration, external store or CAPTCHA.
- Dialogs use a stable mounted native modal and lifecycle effect, focus restoration, Escape support and mobile scrolling. Notices expire once per event, unaffected by roster updates.
- Verify upgrades from Stage 1 serialized fixtures, question-bank changes, removal/reconnect ordering, permissions, limits, invite form/session protection, QR payload and dialog lifecycle. Re-run all existing runtime integration tests, typecheck and production build. Keep test data isolated from local/production rooms.
